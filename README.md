# 🐾 Studio Veterinario "Cuore di Roma" - Progetto d'Esame Web Design

Progetto di prototipazione UX/UI realizzato per l'esame del corso di Web Design / Elementi Grafici.

## 📋 Dettagli del Progetto
* **Tipologia Struttura:** One Page responsive.
* **Dispositivi Progettati:** Desktop e Smartphone (iPhone).
* **Software Utilizzato:** Figma.

## ✨ Elementi Obbligatori Implementati
1. **Privacy e Cookie Policy:** Banner interattivo e checkbox di consenso nel form.
2. **Form di Raccolta Contatti:** Campi strutturati per la prenotazione della visita con validazione e conferma.
3. **Mappa con la Sede:** Sezione contatti integrata con localizzazione a Roma.
4. **Definizione dei Servizi:** Sezione dedicata con card descrittive per medicina generale, chirurgia, diagnostica e pronto soccorso.
5. **Identità Visiva:** Utilizzo del logo ufficiale "Cuore di Roma" e palette cromatica coordinata.
